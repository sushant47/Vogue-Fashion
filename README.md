Simply visit the Vogue Vibe website and start shopping!

1. **Browse Collections** - Explore trending items and special deals
2. **Add to Wishlist** - Save items you love
3. **Add to Bag** - Start building your order
4. **Checkout** - Complete your purchase with ease

### For Developers / Running Locally

**Prerequisites:**

- Node.js (v18 or higher)
- npm or yarn

**Installation Steps:**

1. Clone or download the project:

   ```bash
   git clone <repository-url>
   cd vogue-vibe---vivid-fashion
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Set up environment variables:
   - Create or update `.env.local` file
   - Add your `GEMINI_API_KEY`:
     ```
     GEMINI_API_KEY=your_api_key_here
     ```

4. Run the development server:
   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:3000`

### Available Commands

- **`npm run dev`** - Start development server
- **`npm start`** - Alternative way to start the app
- **`npm run build`** - Create production build
- **`npm test`** - Run tests
- **`npm run lint`** - Check code quality
